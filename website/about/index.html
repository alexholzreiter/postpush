ABOUT THE PROJECT

Built to make the mailbox heard.

PostPush began with one practical goal: turn a mailbox sensor event into a message that reaches exactly the rooms that should hear it.

WHY IT EXISTS

A focused bridge, not another cloud.

The project connects Home Assistant and MQTT with local Piper speech, OwnTone, and AirPlay while keeping event data, audio files, and playback settings on the owner's server. The web interface makes this chain approachable without hiding the realities of a local smart-home system.

Its source code is public under the MIT License. Contributions, bug reports, and technical discussions take place on GitHub.
